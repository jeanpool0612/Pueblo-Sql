🏘️ PUEBLO SQL

¿De qué va esto?

En este pueblo los datos son los vecinos y las casas. Cada vecino te pide algo, tú escribes una consulta en SQL y el resultado se ve en el mapa.

🗂️ Tabla
Una lista: vecinos, casas, parcelas…
➡️ Fila
Un elemento de la lista: un vecino.
📋 Columna
Un dato: nombre, edad…

Tres mundos, de menos a más:

🔎 Consultas: SELECT FROM WHERE AND / OR ORDER BY

🏗️ Construir tablas: CREATE DATABASE CREATE TABLE INSERT PRIMARY KEY UNIQUE NOT NULL AUTO_INCREMENT DEFAULT CHECK

🔗 Relaciones: FOREIGN KEY ON DELETE CASCADE SET NULL DROP tipos de datos

Si te atascas, la 🦉 lechuza te da hasta 3 pistas. Cuantas menos uses, más estrellas ganas.
